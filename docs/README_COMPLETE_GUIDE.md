## 🔴 المشاكل المكتشفة

### المشكلة 1: البيانات لا تظهر في الواجهة

```
الأعراض:
├─ Products page فارغة
├─ Dashboard بدون بيانات
├─ Customers/Suppliers/Expenses فارغ
└─ UI يعرض لكن بدون محتوى

السبب:
├─ قاعدة البيانات قد تكون فارغة
├─ DbInitializer لم تملأ البيانات
└─ أو بيانات جزئية تمنع الـ seeding

الحل: حذف smartpos.db وإعادة تشغيل البرنامج
```

### المشكلة 2: ViewModels استخدم Fire-and-Forget Async

```
الأعراض:
├─ تأخر في ظهور البيانات
├─ قد لا تظهر البيانات إطلاقاً
└─ لا يوجد معالجة للأخطاء

السبب:
├─ MainPOSViewModel: _ = LoadQuickDataAsync();
├─ ProductsViewModel: تحميل في Page_Loaded فقط
└─ DashboardViewModel: نفس المشكلة

الحل: تطبيق نمط موحّد مع error handling
```

### المشكلة 3: أنماط تحميل غير موحّدة

```
الحالي:
├─ بعض Models تحمّل في Constructor
├─ بعضها تحمّل في Page_Loaded
├─ بعضها لا تحمّل إطلاقاً
└─ لا يوجد معايير واضحة

المطلوب:
├─ نمط موحّد لجميع Models
├─ تحميل في InitializeAsync()
├─ Error handling شامل
└─ Status messages واضحة
```
