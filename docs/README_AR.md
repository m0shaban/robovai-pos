## 🎨 تصميم الواجهة (Al‑Atmani 2026)

الواجهة الحالية تعتمد أسلوب **Al‑Atmani 2026**:

- وضع داكن افتراضي (Dark Mode First)
- أسطح زجاج/أكريليك (Glass/Acrylic)
- لوحة معلومات بنمط Bento Grid
- كاشير لمس (Touch‑First) مع زر Checkout واضح

> ملاحظة: بعض الملفات القديمة تشير إلى “Space Edition / SpaceTheme” كتوثيق/تصميم قديم (Legacy).

> ملاحظة (فبراير 2026): `SpaceTheme.xaml` **لم يعد يعمل افتراضيًا** لتجنب أي تداخل. يمكن تفعيله يدويًا من `src/SmartPOS.WPF/appsettings.json` عبر `Ui:EnableLegacySpaceTheme: true`.

## 📋 نظرة عامة

**Smart POS** هو نظام نقاط بيع ومتجر صغير متكامل تم تطويره باستخدام **.NET 8** و **WPF** مع **Material Design**.  
يوفر النظام واجهة عربية كاملة، سهلة الاستخدام، وسريعة للمحلات التجارية والمتاجر الصغيرة والمتوسطة.

## 📁 البنية المعمارية (Clean Architecture)

```
SmartPOS/
├── SmartPOS.Core/              # الطبقة الأساسية (Entities + Interfaces)
│   ├── Entities/               # الكيانات الأساسية
│   └── Interfaces/             # الواجهات
│
├── SmartPOS.Infrastructure/    # طبقة البنية التحتية
│   ├── Data/                   # DbContext + Migrations
│   ├── Repositories/           # تطبيق الـ Repositories
│   └── Services/               # خدمات الطباعة والباركود
│
├── SmartPOS.Application/       # طبقة التطبيق (Business Logic)
│   └── ViewModels/             # ViewModels للواجهات
│
└── SmartPOS.WPF/               # طبقة العرض (Presentation)
    ├── Views/                  # صفحات XAML
    └── App.xaml                # تطبيق WPF
```


## 🖨️ الطباعة

### دعم الطابعات الحرارية:

- ✅ **بروتوكول ESC/POS**
- ✅ طباعة الفواتير
- ✅ طباعة تقرير Z
- ✅ فتح درج النقدية

### أنواع الطابعات المدعومة:

- طابعات 80mm الحرارية
- طابعات 58mm الحرارية
- أي طابعة تدعم ESC/POS

### ملاحظات مهمة

- اختيار الطابعة يتجنب الطابعات الافتراضية (مثل OneNote/PDF/XPS) قدر الإمكان.
- في SQLite قد تحدث مشاكل عند استخدام `SUM` مع قيم `decimal` في الاستعلامات؛ تم استخدام طريقة آمنة (جمع كـ `double?` ثم تحويل إلى `decimal`) داخل مسارات التقارير/الوردية/الداشبورد.
